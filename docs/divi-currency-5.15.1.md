## Changelog

### 5.15.1 (10-10-2026)

- Improved AI Agent image replacements so page-wide placeholder and semantic photo updates use far fewer tokens.
- Fixed the Divi Builder button appearing for users without permission to toggle the Divi Builder.
- Fixed inline SVG stroke colors and widths not rendering in the SVG and Code modules.
- Fixed Divi 4 Video play-icon hover CSS applying when hovering the whole module after migration.
- Fixed nested module entrance animations not playing after the first Group Carousel slide.
- Fixed Woo Product Add To Cart modules in Loop Builder so eligible products honor WooCommerce's archive AJAX add-to-cart setting without leaving the Shop page.
- Fixed Visual Builder freezing when editing large HTML in the Code Module.
- Fixed Gallery Slider Image Design styles so width, alignment, border, and box shadow render on the photos.
- Fixed enabling the Divi Builder on the WooCommerce Shop page when the Classic Editor is enabled.
- Improved Divi AI agent efficiency by keeping only the latest page layout in later AI requests.
- Fixed the Visual Builder module settings panel appearing to shake when hovering the scrollbar in modules with long settings content, such as the Gallery module with many images.
- Fixed background image blend modes not applying in the Visual Builder and frontend when inherited from presets.
- Fixed Pricing Tables Vertical Gap default of 0 not applying in the Visual Builder or on the front end. https://github.com/elegantthemes/Divi/issues/52290.
- Fixed the Woo Product Rating spacing margin-bottom spinner when using three-decimal values and stopped showing a misleading default margin in module spacing settings.
- Fixed Group Carousel equal-height behavior in frontend and Visual Builder by ensuring structural flex layout rules are always emitted.
- Fixed an issue where sticky posts appeared at the top of every paginated Loop Builder page instead of only the first page.
- Fixed Contact Form submissions allowing line breaks from submitted name or email values to reach mail headers.
- Fixed custom fields assigned to user role forms not rendering in the Person module's Position field (or any custom field dynamic content) on Theme Builder templates.
- Fixed misleading global module save warning when changing an image on a global module instance with selective sync disabled for that image field.
- Fixed WooCommerce category and stock product filters not updating products when the shop page uses a Divi 5 Theme Builder template with the Woo Products module.
- Hovering empty Responsive Editor CSS rows no longer changes the active breakpoint while you edit custom CSS in the Visual Builder.
- Fixed Price Range fields overflowing narrow Post Filter module containers.
- Fixed the Bar Counters fill animation so it plays smoothly after reloading Visual Builder.
- Fixed Blurb Layout justify content and related flex alignment options not applying when the module had min-height or height, including with left or right icon placement.
- Fixed an issue where Global Colors could not be scrolled in List View when opening the Color Picker from a Background Gradient stop.
- Fixed Divi AI Agent not applying Fade, Blur, Rotate, Horizontal Motion, and Scaling scroll effects.
- ePanel custom keywords no longer log an undefined `$postid` warning on no-post requests such as 404 and empty-search pages.
- Fixed Gutenberg video URLs appearing in Visual Builder loop excerpts.
- Fixed nested Group modules inside a Group Carousel slide incorrectly labeled as “Carousel Slide” in the Visual Builder Layers panel.
- Fixed WooCommerce product images disappearing after automatic Post Filter updates.
- Fixed Transform Skew errors in hover and responsive editing when the desktop value was blank.
- Fixed an issue where Grid Offset rules configured in the Gallery module rule editor did not save after closing module settings.
- Fixed generated headers to use the configured site logo or Site Title Dynamic Content.
- Fixed the WooCommerce Return to Shop button shifting when hovered.
- Fixed Tooltip so an open tooltip stays with its target when scrolling instead of sticking to the bottom of the screen.
- Fixed global module instances and selective-sync descriptors not migrating legacy form field focus styling paths.
- Reduced duplicate Dynamic Content options requests when editing modules with many dynamic fields.
- Fixed the Post Filter module showing a select dropdown arrow on mobile when the field type was set to checkbox (or another non-select type) for that breakpoint.
- Added safeguards to avoid variable data loss in the event of an unforeseen future bug leading to incorrect variable array merging.

### 5.15.0 (10-09-2026)

- Global modules are now components, including a host of new functionality.
- Improved performance of editing sub elements within a parent component, ensuring the save operation does not cause re-renders that slow down module adding/deleting/duplicating.
- Added a new method for converting static modules into existing components, mapping static attributes to matching unsynced attributes within the component.
- Components now support select sync on nested module attributes.
- Introduced a new component editing mode, which separates the editing of local and global component attributes.
- Fixed a bug where multiple instances of the same component could get out of sync when moving modules nested within the parent component.
- Added the new Slot module, which can be used inside component to create slots of local-instanced modules within the global component.
- Saving confirmation is no longer required when navigating between different nested modules within the same parent component.
- Presets can now be applied on the local instance on top of presets moused within components.
- The selective sync icon for components was moved from the left of fields into the existing field label icon group for consistency.
- Fixed a bug where the back button didn't display properly when editing a module within an unsynced elements group within a component.
- Fixed dragging nested modules out of a component and then back into a duplicate instance of the original component; now that removable/addition from and to the same parent module acts as a module move within the parent component.
- Detached global module attributes now inherit default values from the parent component.
- Components now import and export with layouts similar to presets and variables.
- Added dedicated components importer and exporter.
- Added new components manager and editor panels, allowing you to edit, delete and duplicate components in the visual builder instead of having to visit the Divi library.
- Nested modules within components can now be completely detached and worked with at the instance level within a parent component.
- Improved performance of resizing and moving undocked panels.
- Components can now have other components nested inside them (for example, a section component supports addition module components within it).
- Fixed components rendering in the wrong order in wireframe view when wireframe view was set as the default workspace view mode.
- Fixed broken components when imported via attached theme builder layouts.
- Added new AI Agent tool for deleting and duplicating components.
- Added new AI Agent tool for converting modules to existing components.
- Added new AI Agent tool for saving modules as components.
- Added new AI Agent tool for updating component attributes.
- Fixed an issue where Loop Builder meta queries using Field Exists (EXISTS) did not filter posts correctly in the Visual Builder when the meta value was left empty.
- Fixed AI Agent removing before and after text from dynamic content in Text Modules when generated layouts used dynamic dates or years.
- Fixed Divi AI nested submenu options not lining up with the parent item when the WordPress admin bar was enabled in Visual Builder.
- Fixed ConvertKit (Kit) Email Optin not showing account custom fields after Fetch Lists when Kit Settings defined subscriber custom fields.
- Fixed multiple Components issues including incorrect frontend rendering for nested Components, stale selective-sync values on the frontend, broken Cancel when editing nested Component sources, invalid drag-and-drop across Slots and synchronized structure, and prevention of self-referencing Component saves.
- Fixed Button module left-aligned custom icons so they no longer overlap the text when a hover icon color is set.
- Fixed canvas images whose filenames contain a `u` followed by four hexadecimal characters.
- Fixed Post Carousel Carousel Item Title Text composable settings applying to the module wrapper instead of the item title.
- Fixed Blog module Read More link text on the frontend so it matches the Visual Builder preview when Show Read More Button is enabled.
- Fixed Call to Action unordered-list styles not being preserved during Divi 4 to Divi 5 migration.
- Fixed frontend Module Elements custom CSS output for Post Filter and Post Filter Item modules.
- Fixed Tab module child parallax background images so they display immediately when switching tabs.
- Fixed Loop Builder excerpts so HTML and line breaks render on the live page when Number of Words is set.
- Fixed Row sticky background colors not rendering in the Visual Builder when the Row is inside a sticky Section.
- Fixed frontend styles breaking on a layout when a spacing value contained an invalid character.
- Fixed the Map module address field not clearing its visible text immediately after reset when a location had been found with the Find button.
- Fixed an issue where a custom z-index was ignored while an element was sticky, so sticky elements could not stack in the configured order.
- Fixed missing global color names in module settings after the AI Agent converts repeated colors into global variables.
- Fixed an issue where the Divi Library save action could overwrite a post the current user is not allowed to edit.
- Fixed Visual Builder crash in the Portfolio module when Post Count contained a space.
- Fixed automatic Post Filter options for ACF choice fields to display configured choice labels instead of stored values.
- Fixed wrong button icon with uppercase text enabled.
- Fixed Background Patterns and Masks not rendering when applied from an Element Preset or a Background Option Group Preset.
- Fixed Instagram Feed modules being limited to 24 posts.
- Fixed importing certain pages and layouts from the library not working in the builder.
