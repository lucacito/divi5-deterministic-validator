JHMG AI Editor for Divi 5 - built-in image pack
================================================

Original artwork generated by a script in the plugin's development repository, © JHMG, released under GPL-2.0-or-later.

Every image in this folder is an original SVG illustration produced by a
deterministic generator script. None of it is a photograph and none of it is
taken from a third-party stock library. The files are served from this plugin's
own folder on your site; nothing is loaded from a remote host.

manifest.json lists every image with its token, role (hero, section-bg, card,
square, avatar, logo), aspect ratio, palette, tone (dark = use light text on it,
light = use dark text on it) and alt text. Page layouts reference images with
tokens such as {{aied:image:hero-blue-1}}, which the plugin resolves to the URL
of the matching file in this folder.
